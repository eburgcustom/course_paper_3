# Парсер вакансий с HeadHunter

## О проекте

Это консольное приложение для сбора и анализа вакансий с сайта hh.ru. Приложение позволяет:

- Получать информацию о компаниях и их вакансиях через API HeadHunter
- Сохранять данные в базу данных PostgreSQL
- Анализировать вакансии: средние зарплаты, поиск по ключевым словам и т.д.
- Просматривать отфильтрованные списки вакансий

## Требования

- Python 3.8+
- PostgreSQL 12+
- Учетная запись с правами на создание базы данных

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-пользователь/ваш-репозиторий.git
   cd ваш-репозиторий
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # для Linux/Mac
   venv\Scripts\activate     # для Windows
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл конфигурации базы данных `config/database.ini`:
   ```ini
   [postgresql]
   host=localhost
   database=hh_vacancies
   user=ваш_пользователь
   password=ваш_пароль
   port=5432
   ```

## Настройка базы данных

1. Убедитесь, что PostgreSQL запущен
2. Создайте базу данных (если она еще не создана):
   ```bash
   createdb hh_vacancies
   ```
3. Инициализируйте структуру базы данных:
   ```bash
   python main.py
   ```
   (При первом запуске база данных будет создана автоматически)

## Запуск приложения

```bash
python main.py
```

После запуска откроется главное меню с доступными действиями.

## Использование

### Главное меню

1. **Загрузить данные**
   - Загрузить тестовые данные (популярные IT-компании)
   - Загрузить данные по ID работодателя
   - Найти работодателя по названию

2. **Просмотр данных**
   - Список всех компаний
   - Все вакансии
   - Средняя зарплата по вакансиям
   - Вакансии с зарплатой выше средней
   - Поиск вакансий по ключевому слову

### Пример работы

1. Запустите приложение: `python main.py`
2. Выберите пункт "Загрузить данные" -> "Загрузить тестовые данные"
3. После загрузки выберите "Просмотреть все вакансии" для просмотра результатов
